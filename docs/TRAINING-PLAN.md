# แผนระบบ "AI ฟังแล้วจัดเนื้อเพลงให้เหมาะกับเพลง" (ผู้ใช้สั่ง 2026-10-21)

เป้าหมายที่ผู้ใช้ตอบมา (ครบทั้งหมด): เนื้อเพลงที่ดีและครบที่สุด · ฟังเสียงแล้วแบ่งท่อน/บรรทัดได้ดีเยี่ยม · เวลารายคำจากการฟัง ·
จัดการคอรัสจากการฟัง · นับว่ามีคนร้องกี่คน (≥2 คน: นักร้องนำที่ร้องมากสุดชิดซ้าย อีกคนชิดขวา) · เทรนให้ดีที่สุด · เก็บข้อมูลสอนจากทุกเพลง
(ของผู้ใช้และของผม) · ใช้ดิสก์/เวลาได้เต็มที่ (หลายชั่วโมง–วัน)

## หลักการ
- แยกเป็นโมดูลที่วัดผลได้ทีละอัน (ไม่เทรนโมเดลก้อนเดียวทำทุกอย่าง): ทุกโมดูลมีชุดวัดผลก่อน-หลัง และถอยกลับได้ (ตัวเลือกใน models.yaml)
- ส่วนที่ไม่ต้องเทรนแต่ได้ผลมาก ทำก่อน: ใช้ "เสียง" เป็นกรรมการตัดสินเนื้อเพลง (CTC ให้คะแนนว่าข้อความฉบับไหนเข้ากับเสียงมากสุด + บรรทัดที่เสียงไม่มีจริง = ตัดทิ้ง)
- ส่วนที่เทรน: (1) ตัวจัดเวลา CTC ปรับให้เก่งกับเสียงร้อง (2) ตัวแบ่งบรรทัด/ท่อน (3) ตัวตรวจคอรัส/นักร้องคนที่สอง
- ข้อมูลเก็บในเครื่องเท่านั้น (`C:\lyrics\dataset\`) ไม่ส่งออกนอกเครื่อง · ไม่ commit เข้า git

## ขั้นตอน (ทำทีละขั้น วัดผล commit ทุกขั้น)
| # | งาน | ต้องเทรนไหม | ตัววัด |
|---|---|---|---|
| 1 | เสียงเป็นกรรมการเลือกเนื้อเพลง: ให้คะแนนผู้สมัครทุกฉบับด้วย CTC, ตัดบรรทัดที่ไม่มีในเสียง, ฉันทามติข้ามแหล่งยังใช้ร่วม | ไม่ | อัตราเลือกฉบับตรง (เทียบเฉลยจาก NetEase/QQ รายคำ) · บรรทัดเกิน/ขาด |
| 2 | นับนักร้อง (speaker embedding บน stem เสียงร้อง → จัดกลุ่ม → นำ=ซ้าย รอง=ขวา) | ไม่ (ใช้โมเดลสำเร็จรูป) | ดูกับดูเอ็ตที่รู้คำตอบ |
| 3 | เก็บข้อมูล: บันทึกอัตโนมัติจากทุกเพลงที่เล่น + สคริปต์ดึงเพลงเพิ่ม (เนื้อรายคำ NetEase/QQ + เสียงจาก YouTube → Demucs → `dataset/`) | ไม่ | จำนวนเพลง/ชั่วโมงเสียง/ภาษา |
| 4 | เทรนตัวแบ่งบรรทัด+คอรัส (โมเดลเล็ก) จากเนื้อเพลงที่มนุษย์ตัดบรรทัดไว้ + เวลารายคำ + ความดังเสียงร้อง | ใช่ (เล็ก CPU/GPU ไม่กี่ชั่วโมง) | F1 ของจุดตัดบรรทัด · F1 คอรัส |
| 5 | เทรนตัวจัดเวลา: fine-tune MMS (wav2vec2 CTC) ด้วยเสียงร้อง + ข้อความ (ใช้ CTC loss ไม่ต้องมีเวลารายคำ) แล้ววัดกับเฉลยรายคำ | ใช่ (หลายชั่วโมง ใช้การ์ดจอ) | median/≤0.15/≤0.3 วิ เทียบ MMS เดิม (0.05 / 73% / 86% บน QLC) |
| 6 | ผูกเข้าแอป (ตัวเลือกเปิดปิดได้) + หน้าตั้งค่า + เอกสาร | — | ทดสอบในแอปจริง |

## ข้อจำกัดที่ต้องรู้
- การ์ดจอ 8 GB: เทรน wav2vec2-large (315M) ได้แบบ fp16 + gradient checkpointing ช่วงเสียง ≤ 20 วิ · ตอนเทรนแอปต้องปิด (VRAM)
- ภาษาไทยมีเฉลยรายคำน้อยในแหล่งเปิด: ตัวจัดเวลาที่เทรนจะเก่งขึ้นกับภาษาที่มีข้อมูลเยอะ (จีน/อังกฤษ/เกาหลี) ไทยอาศัยการถ่ายโอน
- ดึงเสียงจาก YouTube จำนวนมากใช้คุกกี้ของผู้ใช้: ตั้งอัตราช้า (≤ 1 เพลง/10 วิ) กันบัญชีถูกจำกัด
