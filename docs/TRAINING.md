# วิธีเทรนโมเดลของ SyncLyrics (ทำเมื่อไหร่ก็ได้ ปิดแอปก่อนเสมอ — ใช้การ์ดจอ)

แผนภาพรวมอยู่ที่ [TRAINING-PLAN.md](TRAINING-PLAN.md) · ที่นี่คือขั้นตอนที่ต้องกดเอง

## 0) สิ่งที่ระบบทำให้อัตโนมัติอยู่แล้ว
- ทุกเพลงที่คุณเปิดจนมี "จัดเวลาจากเสียงจริง" แอปเก็บข้อมูลสอนไว้ที่ `C:\lyrics\dataset\songs\<videoId>\` (เสียงร้อง ~6 MB + เนื้อเพลงทุกฉบับ + ผล AI) และเก็บการกระทำของคุณ (กด "ตัวอื่น", ปรับเวลา) ใน `dataset\events.jsonl` · ปิดได้ที่ตั้งค่า > การซิงก์ > "เก็บข้อมูลสอนจากเพลงที่ฟัง"
- ใช้ฟังเยอะๆ ตามปกติ ข้อมูลยิ่งเยอะยิ่งดี

## 1) เตรียมชุดข้อมูลมาตรฐาน (เฉลยจากมนุษย์) — ทำครั้งแรกให้เยอะๆ
```
scripts	rain_all.bat 2000
```
ทำตามลำดับ: ดึงเพลง (NetEase + เสียงจาก YouTube ผ่าน cookies ของคุณ + Demucs) → เทรนตัวแบ่งบรรทัด → วัดตัวจัดเวลาเดิม → เทรนตัวจัดเวลา

**แผนหมวด 2000 เพลง** (สลับหมวดทุกช่วง หยุดตรงไหนก็สมดุล · ผสมเพลงช้า/เร็วในทุกหมวด):
| หมวด | เป้าหมาย |
|---|---|
| ไทย | 350 |
| สากล (ตะวันตก) | 480 |
| เกาหลี (K-pop + K-indie) | 380 |
| ญี่ปุ่น | 260 |
| จีนดัง | 330 |
| รีมิกซ์ (Douyin DJ) | 20 |
| ช้า/เร็วผสมเพิ่ม | 180 |

- ดูรายการที่จะดึงก่อน: `.venv\Scripts\python scripts\harvest.py --plan 2000 --list` (บันทึกที่ `dataset\harvest_queue.txt` · มีตัวเลือกเผื่อ ~4,500 เพลง เพราะบางเพลงไม่มีเนื้อ/วิดีโอ)
- เวลา ~35 วินาที/เพลง → 2000 เพลง ≈ **19–20 ชั่วโมง** (ปล่อยข้ามคืนหลายคืนได้ รันซ้ำทำต่อจากเดิม) · ดิสก์ ~12 GB · หน่วงระหว่างเพลง 8 วินาที กัน YouTube จำกัดบัญชี (ถ้าเจอ error ขอล็อกอินบ่อย ให้เพิ่ม `--sleep 15`)
- เพลงที่ NetEase มีแค่เนื้อระดับบรรทัด (เพลงไทยส่วนมาก) ใช้เทรนตัวจัดเวลาได้ แต่ไม่ใช้วัดเวลารายคำ (ต้องมีเนื้อรายคำ — เพลงสากล/จีน/เกาหลี/ญี่ปุ่นส่วนมากมี)
- เพลงเฉพาะ/ที่เคยเล่นในแอป: `harvest.py --queries my_songs.txt --no-playlists` หรือ `--from-db <สำเนา synclyrics.sqlite3> --no-playlists` (ห้ามชี้ไฟล์จริงของแอป)

## 2) ดูผล
- `scripts\eval_aligner.py --split val` พิมพ์ median / ≤0.15 วิ / ≤0.3 วิ ของเวลาเริ่มคำ (ยิ่งต่ำ/สูงตามลำดับยิ่งดี) · ตัวเลขเดิมของ MMS: median 0.05–0.09 วิ, ≤0.3 วิ 86–90%
- `train_ctc.py` เก็บน้ำหนักที่ดีที่สุดที่ `ai_runtime\models\mms_singing.pt` เฉพาะเมื่อดีกว่าของเดิมบนเพลง val · บันทึกผลรายรอบที่ `dataset\train_log.jsonl`
- `train_lines.py` พิมพ์ F1 ของจุดตัดบรรทัด/เสียงประสาน เทียบ baseline

## 3) ใช้โมเดลที่เทรนได้
- ตัวจัดเวลา: ใส่ใน `config\models.yaml` → `align: finetuned: ai_runtime/models/mms_singing.pt` (ต้องแก้ค่านี้เองหลังเห็นว่าดีกว่าจริง)
- ตัวแบ่งบรรทัด/เสียงประสาน: ยังไม่ผูกเข้าแอป (รอผลเทรนจริง) — บอก Claude หลังเทรนเสร็จพร้อมตัวเลข จะผูกให้และวัดซ้ำในแอป

## ข้อควรรู้
- ปิดแอปก่อนเทรน (การ์ดจอ 8 GB ไม่พอทั้งสองอย่าง) · เทรนเองไม่เสีย usage ของ Claude
- ถ้าการ์ดจอเต็มตอนเทรน ลด `--batch 2` หรือ `--max-clip-s 10` หรือ `--freeze-layers 12`
- เพลงที่ติดธง suspect (เฉลยไม่เข้ากับเสียง YouTube) ไม่ถูกใช้ ปกติ ~30–40% ของที่ดึงมา
